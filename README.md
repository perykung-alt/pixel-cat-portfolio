# 🐱 Pixel Cat Portfolio

Widget พอร์ตการลงทุนสำหรับ iPhone (แอป [Scriptable](https://apps.apple.com/app/scriptable/id1405459188)) พร้อมแมวพิกเซลที่ใช้ชีวิตตามเวลาตลาดจริงและอารมณ์ของพอร์ต

- หุ้นไทย · หุ้น/ETF ต่างประเทศ · กองทุนรวม · คริปโต (ราคา Bitkub) · ทองคำแท่ง 96.5% (ราคาฮั่วเซ่งเฮง)
- นำเข้าพอร์ตจากรูปแคปหน้าจอด้วย AI ทีละหลายรายการ
- เวลาตลาด SET / NYSE ตามจริง รวมวันหยุดและ Daylight Saving
- widget เล็ก / กลาง / ใหญ่ / หน้าจอล็อก
- **อัปเดตอัตโนมัติ** จาก repo นี้ทุก 6 ชั่วโมง

## 📱 Android / คอม (เว็บแอป)

เปิด **https://perykung-alt.github.io/pixel-cat-portfolio/** ใน Chrome แล้วกด **⋮ → เพิ่มลงหน้าจอหลัก** (หรือปุ่ม 📲 ติดตั้งเป็นแอป ในแท็บ ⚙️) จะได้ไอคอนแมวเหมือนแอปทั่วไป

- แมวขยับได้จริงในห้อง แตะเพื่อเล่นด้วย · อัปเดตเวอร์ชันเองทุกครั้งที่เปิดแอป
- ราคาหุ้น/คริปโต/ทอง/ค่าเงินดึงโดย GitHub Actions ทุก ~15 นาที ไว้ที่ `data/prices.json`
- หุ้นที่ระบบยังไม่มีราคา: กรอกราคาเองได้ หรือเปิด Issue หัวข้อ `add SYMBOL` (เช่น `add PTT`, `add VOO us`) ระบบจะเริ่มดึงให้ในรอบถัดไป
- ย้ายข้อมูลจาก iPhone: เมนู 💾 สำรอง → คัดลอก แล้ววางในเว็บแอปที่ ⚙️ → สำรอง / ย้ายข้อมูล
- ข้อจำกัด: เป็นไอคอนแอป ไม่ใช่ widget บนหน้าจอ · ยังไม่รองรับดึงยอดจาก Bitkub API key

## ☁️ บัญชี Google (เว็บแอป + แอป Android)

เข้าสู่ระบบด้วย Google ที่แท็บ ⚙️ เพื่อเก็บพอร์ตไว้บน Firebase Firestore (`users/{uid}`) ข้อมูลซิงก์อัตโนมัติทุกครั้งที่แก้ไข และใช้ร่วมกันได้ทุกเครื่อง กฎความปลอดภัยอยู่ใน [`firestore.rules`](firestore.rules) (แต่ละคนอ่าน/เขียนได้เฉพาะของตัวเอง) · ในแอป Android การล็อกอินจะเปิด Chrome ที่หน้า `login.html` แล้วส่งกลับเข้าแอปผ่าน `pixelcat://auth`

## 🍎 iPhone — ติดตั้ง widget (ครั้งเดียว)

1. ติดตั้งแอป **Scriptable** (ฟรี)
2. เปิดแอป กด **+** สร้างสคริปต์ใหม่ แล้ววางโค้ดจากไฟล์ [`install.js`](install.js)
3. กด ▶︎ ครั้งเดียว จะได้สคริปต์ชื่อ **Pixel Cat Portfolio** แล้วลบสคริปต์ติดตั้งทิ้งได้
4. กดค้างที่หน้าโฮม → เพิ่ม widget ของ Scriptable → แตะ widget → เลือกสคริปต์ **Pixel Cat Portfolio**

หรือจะวางโค้ดจาก [`PortfolioWidget.js`](PortfolioWidget.js) ลงไปตรงๆ ก็ได้ ผลเหมือนกัน

## ข้อมูลส่วนตัว

ข้อมูลพอร์ต การตั้งค่า และ Bitkub API key เก็บอยู่ในเครื่องของแต่ละคนเท่านั้น (iCloud Drive/Scriptable/PortfolioWidget และ Keychain) repo นี้มีแค่โค้ด การอัปเดตจะเขียนทับเฉพาะตัวสคริปต์ ไม่แตะข้อมูล

## สำหรับผู้ดูแล: ปล่อยเวอร์ชันใหม่

1. แก้ `PortfolioWidget.js` และเปลี่ยน `const VERSION = "x.y.z"` (โค้ดระหว่าง `// @shared-begin` … `// @shared-end` ถูกใช้ในเว็บแอปด้วย — `node scripts/build.mjs` สร้าง `_site/`)
2. แก้ `version.json` ให้ `version` ตรงกัน และใส่ `notes`
3. Commit + push ไปที่ `main` เครื่องที่ติดตั้งไว้จะอัปเดตเองภายใน ~6 ชั่วโมง (หรือกดเมนู 🔄 อัปเดต)

สคริปต์จะตรวจไฟล์ใหม่ก่อนเขียนทับ (เวอร์ชันต้องตรงกับ `version.json` และ syntax ต้องถูกต้อง) และสำรองเวอร์ชันเดิมไว้ที่ `PortfolioWidget/backup-v*.js`
